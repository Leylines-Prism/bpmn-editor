# Prompt pour un agent MCP

*À donner à un agent relié à BPMN-Pilot par MCP (version Docker) et aux outils de Néréide Networks (wiki, ITSM). Exemple fictif.*

> Dans le wiki de Néréide Networks, lis la procédure « Mise en service SD-WAN » et la politique de gestion des changements, puis les 20 derniers tickets de bascule de l'ITSM. Dessine dans BPMN-Pilot le processus réellement suivi : un pool pour le client, un pour Néréide Networks, un couloir par équipe, et le change en sous-processus. Signale dans ta réponse chaque écart entre la procédure écrite et les tickets.
