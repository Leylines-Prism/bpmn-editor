BPMN Editor guide

A free BPMN 2.0 editor in your browser, with no account and nothing to install. Draw your processes by hand, or describe them to an AI assistant that draws them for you.

Open the editor Let the AI draw

Getting started

Every new diagram starts with a small process: a start, a task and an end. That is true the first time you open the editor and each time you click New. Build from there, or delete these shapes to draw something else.

  1. Pick a shape in the palette, left of the canvas, then click the canvas to place it.
  2. Click a shape: its context menu appears next to it. It appends the next element, already connected.
  3. Double-click a shape to type its label.
  4. Name the file in the field on the left of the toolbar. That name is used when saving and for every export.

Your work is kept in the browser after every change. Reopen the page and you find it as you left it. The toolbar shows this as "Autosave".

The FR or EN button switches the interface language, and the round button next to it picks the theme: light, dark, or your system's. The browser remembers both choices.

There is no account. Your diagrams stay in your browser. If you use the assistant, only the AI provider receives them. Neither this site nor its host has access to them. The site only measures its audience, without cookies (see Privacy).

Drawing

The palette

The palette on the left holds the selection tools (hand , lasso , space , connect ) and then the shapes: events, tasks, gateways, subprocesses, data objects, pools and lanes. The button at the bottom of the palette opens the full list of BPMN elements, with a search by name.

The context menu

When you select an element, a set of buttons appears next to it. Which buttons you get depends on the element type. For a task, you will find:

  • First row: append an end event, a gateway, a task or an intermediate event. The new element is placed to the right, already linked by a flow.
  • Add text annotation (the dotted bracket) adds a comment linked to the element.
  • Append element (the three dots) opens the full list of elements that can follow, sorted by family (tasks, gateways, sub-processes, events, data), with a search field.
  • Connect to other element (the slanted arrow): click it, then click the target element to draw a flow.
  • Change element (the wrench) turns the element into another type without redrawing it: its links and label are kept. See the details below.
  • Delete (the bin) removes the element and its flows.
  • Set color (the brush) and Text formatting (the A button) are covered in Colors and text.

Change element

The wrench opens the Change element window. It lists the types that fit the selected element: a task can become a user task, a service task, a call activity or a sub-process, a start event can become a message or timer start event, and so on. Type a few letters in the search field to filter the list, then click a type or press Enter. The R key opens the same window from the keyboard.

For a task or a sub-process, the icons at the top right of the window add a marker without changing the type: parallel multi-instance , sequential multi-instance and loop . Click again to remove the marker. You then set the loop cardinality and completion condition in the Process panel.

The minimap

The minimap shows a small view of the whole diagram, top right of the canvas. It is collapsed when the editor opens: click Open minimap to expand it, then Close minimap to collapse it.

  • The orange frame is the part of the diagram visible on screen. Drag it to move around.
  • Click anywhere else in the minimap to center the view on that point.
  • Ctrl+wheel over the minimap zooms the canvas.

On the canvas, the grid helps you line shapes up, and they snap to it.

Process panel

The right-hand panel shows the properties of the selected element. When nothing is selected, it shows those of the process, or of the collaboration if the diagram has pools. Its header gives the element type (User task, Message start event…) and its label.

Show and hide the panel

  • The button at the far right of the toolbar hides the panel. Click it again to bring the panel back. The canvas takes the freed space, and the browser remembers your choice for next time. This button has no keyboard shortcut.
  • To change the width, drag the handle on the left edge of the panel. With the keyboard, move to the handle with Tab and use the left and right arrows. Double-click the handle to go back to the default width.

Name, ID and Executable

Every element has the General group.

  • Name is the label shown on the diagram. Changing it here is the same as double-clicking the shape.
  • ID is the technical reference of the element in the XML file. It is not shown on the diagram. The file uses it to link elements together (a flow to its task, a pool to its process), and execution engines use it to identify a step. It must be unique in the diagram and contain no spaces. The panel shows a message under the field when a value is refused. The editor assigns one automatically, so you only need to change it if an external tool expects a specific value.
  • Executable only applies to the process. When checked, it states (the isExecutable attribute) that a workflow engine such as Camunda or Flowable can deploy and run this process. For a diagram meant for documentation or analysis, you can leave it unchecked.

For a pool, the General group holds the name and ID of the pool, then the name and ID of the process it contains, with its Executable box. This is where you find the process settings once the diagram has pools.

Everything you enter in the panel is saved in the .bpmn file and carried over to XML exports.

Colors and text

Colors

The brush in the context menu offers 18 colors, each with a pale fill and a readable dark stroke. Custom color… accepts any shade. The stroke is then computed to stay readable, and a dark fill gets light text.

Text formatting

The A button in the context menu formats the label: bold, italic, underline, size (10 to 24), font (sans serif, serif, monospace) and color. The Auto color picks black or white, whichever reads better on the element's fill. Default text removes all formatting.

Colors and styles are saved in the .bpmn file following the standard, and other bpmn.io tools read them back. Underline does not show in the PDF export.

Check, tidy up, simulate

BPMN correctness checks

The editor has a built-in BPMN correctness checker, bpmnlint. It checks the diagram while you draw, with its 27 recommended rules: disconnected element, process with no start or end, badly connected gateway, element without a label… They are advice: the diagram saves even if some remain.

  • A badge on the element flags an issue: red for an error, orange for a warning.
  • Hover the badge to read the message. The rule name follows in brackets, for example no-implicit-end.
  • Click that name to open the rule's explanation, with a wrong and a right example.
  • The counter at the bottom left of the canvas shows the number of errors and warnings. Click it to hide or show the badges.

Tidy up

The Tidy up button (after My diagrams) recomputes the layout of the whole diagram, from left to right. Useful after an import, or after a diagram drawn by the AI.

Tidy up moves every shape and clears the undo history. The editor asks you to confirm. To keep the previous version, save it in My diagrams first.

Simulation

The Simulation button (next to Tidy up) switches to simulation mode: a play button appears on each start event. Click it to send a token, and watch it follow the flows. At exclusive gateways, you choose the path. A log shows the steps taken. This shows whether the process ends in every case. Click Stop simulation to go back to editing.

Saving and My diagrams

Autosave

The current diagram is kept in your browser one second after each change. The time shown next to "Autosave" is the time of the last save. There is only one current diagram: clicking New or opening a file replaces it.

My diagrams

To keep several diagrams, open My diagrams. Save the current diagram under a name, then reopen, rename or delete your diagrams. Once a diagram is saved, Ctrl+S updates it. Save as new makes a copy.

My diagrams lives in this browser, on this device. It is not synced, and it is lost if you clear the site's data or browse in private mode. To keep a diagram for good, or share it, export it as a .bpmn file.

Open, import, export

Open

  • Open, then .bpmn or .xml file…, opens a file from your disk.
  • Paste XML… opens a diagram copied as code, for example from another tool or an AI answer.
  • You can also drop a .bpmn file onto the page.

The editor reads BPMN 2.0 files from other tools (Camunda, Bizagi, Signavio…). If a file has no diagram layout, the editor computes one when it opens.

Every export uses the file name shown in the toolbar.

Print

Export, then Print… opens the browser's print window on the diagram alone. It is centered on one page, with 10 mm margins. The page turns to landscape if the diagram is wider than tall, portrait otherwise. Safari lets you choose the orientation in its print window. A large diagram is shrunk to fit the page, a small one keeps its on-screen size. For a very long process, the PDF or SVG export lets you zoom in.

AI assistant

The AI assistant button in the toolbar opens a chat panel. Describe a process there, and the assistant draws it straight into the editor. It can also change the open diagram, tidy it up and check it. Then you touch up its work by hand, like any other diagram.

1. Choose a provider

The assistant uses an AI model from the provider of your choice, with your own API key. Open Options in the assistant panel:

ProviderWhat to know
MistralCreate a key at console.mistral.ai. Calls go straight from this page. For processing in the European Union, change the address to https://api.eu.mistral.ai/v1 (billed 10% more). Mistral models also read images, not PDFs.
Anthropic (Claude)The simplest in this version: create a key at console.anthropic.com. Claude models also read images and PDFs.
OpenAICreate a key at platform.openai.com. OpenAI does not always accept calls made from a web page: if "Test" fails, this provider will not work here.
OllamaFree models, on your own computer. Ollama must be started with the OLLAMA_ORIGINS variable set to this site's address (Options gives you the exact value). Pick a model that supports tool calls.
OpenAI-compatibleLiteLLM, LM Studio, vLLM… The server must use https (or localhost) and allow this site's address in its CORS setting.

Paste the key, click Test, then choose the model. A provider's models are offered once its connection is tested. The panel shows which model is in use.

2. Describe the process

Write it the way you would explain it to a colleague: who does what, in which order, with which decisions. The assistant answers in the language of your message. For example:

"Draw the expense claim process. The employee enters the claim, their manager approves or rejects it. Above €500, accounting approves it too. Once approved, it is paid within 5 days. Use one lane per role."

Under each answer, small tags show what the assistant did to the diagram: reading, adding shapes, connections, layout… Then ask it for changes ("add a reminder if the manager does not answer within 3 days"), or make them yourself.

  • The input box grows with the text. The button in its corner opens a large editor, to paste long text or open a .txt or .md file. Ctrl+Enter sends.
  • New chat starts over. The diagram does not change.
  • Stop interrupts an answer in progress.

3. Start from an image or a PDF

The assistant can also start from a whiteboard photo, a screenshot of an old tool or a procedure in a PDF. Paste the image (Ctrl+V), drop it on the panel, or pick it with the paperclip, then ask the assistant to draw it. Up to 5 files per message: images up to 5 MB, PDFs up to 20 MB. Claude models read both. With other providers, images depend on the model, and PDFs only work with OpenAI.

See what the assistant changed

After each answer, the shapes the assistant added get a thin magenta outline and a dot, the shapes it changed a dashed outline. A pill at the top of the canvas sums up, for example "AI: 2 added, 1 changed, 1 removed". Hover over the pill to see the names of the removed shapes.

  • When the assistant changes a lot at once, such as a diagram drawn from scratch, no outline is shown: the pill alone sums up. Click the pill to show the outlines, click again to hide them.
  • Your own edits and automatic layout are never marked. Ctrl+Z updates the marking.
  • The marking is cleared by the pill's cross, by your next message, or when another diagram is opened. It never appears in the file or in exports.

What it costs

The editor is free. AI calls are billed by the provider, to your account, at its rates. The cost depends on the model and the size of the diagram: each message sends the current diagram. With Ollama, on your own computer, there is nothing to pay. To stay in control, set a spending limit in your provider's console.

Your API keys

Your key never goes through this site or its host (GitHub Pages). It stays in your browser and goes straight to the chosen provider with each message. Where it is kept depends on the Remember API keys on your device box in Options:

BoxWhere the key isUntil when
Unchecked (default)The tab's session storageErased when you close the tab
CheckedThe browser's local storageKept until you click Clear API keys

What protects it: the page runs no script from anywhere else (a content security policy forbids it), and the key is only sent to the chosen provider. However, a malicious browser extension, or someone using your session, can read it.

On a shared computer, leave the box unchecked and close the tab when you leave.

Responsible use

Use, first and foremost, an API key dedicated to this editor, created for it alone, with a limited validity period. Add a spending limit if your provider allows it. If it leaks, the key only works here, expires on its own and can be deleted without affecting anything else you use.

Privacy

  • Your diagrams, settings and API keys stay in your browser. They are not sent to us, nor to the host of this site (GitHub Pages).
  • If you use the AI assistant, your messages, the diagram, your attached files and your key go straight from your browser to the chosen provider, which applies its own terms and privacy policy. Do not include data you would not trust that provider with.
  • Like any web host, this site's host (GitHub Pages) keeps technical logs, such as your IP address.
  • The site measures its audience with Umami, without cookies, according to the recommendations of the CNIL (the French data protection authority) for audience measurement exempt from consent. The IP address is not recorded. It is only used to determine the country, region and city. The data collected is: the page viewed and the referring site, the device characteristics sent by the browser, and a few actions without their content (creating, opening or exporting a diagram, using the assistant, type of provider connected, active time in ranges). "Do Not Track" and "Global Privacy Control" signals turn the measurement off.
  • The site loads no third-party script.

The Privacy link at the bottom of the canvas repeats these points in the editor.

Docker version and MCP agents

This site is the online version. The editor also comes as a Docker version, to install on your machine or private network. It adds:

  • API keys stored on your server, which never reach the browser,
  • every provider, OpenAI included, with no browser blocking,
  • My diagrams also saved on the server, available from several browsers,
  • an MCP server: an agent such as Claude Code, Claude Desktop or GitHub Copilot in VS Code can draw in the open editor, and its changes are marked like the assistant's. Click the MCP badge in the toolbar for the address and ready-to-paste settings.

Installation is described in the project README on GitHub.

FAQ

Do I need an account?

No. The editor works without an account. Only the AI assistant needs an API key from an AI provider.

Can I use the editor without AI?

Yes. The whole editor works without an API key: drawing, checks, simulation, saving and exports.

My diagrams are gone. What happened?

They are stored in the browser. They do not show in another browser, on another device, in private mode, or after the site's data is cleared. Export what you want to keep as .bpmn.

"Test" fails with OpenAI.

OpenAI sometimes refuses calls made directly from a web page. Use Anthropic or Ollama on this site, or install the Docker version, which goes through its own server.

The assistant drew something unexpected.

Undo with Ctrl+Z, or ask it for the fix in a few words. The more precise the description (roles, decisions, error cases), the better the result. A stronger model also helps with large processes.

Can I open my files in another BPMN tool?

Yes. The .bpmn file follows the BPMN 2.0 standard and opens in Camunda Modeler, Bizagi, Signavio and other compatible tools.

Does it work on a phone or tablet?

The page displays, but the editor is made for a computer screen, a mouse and a keyboard.
